# COS 文档上传实现计划

## 目标

将后台文档新增改为两阶段会话：浏览器先上传到后端受控临时目录，后端同步生成试看 PDF 和首页缩略图；管理员确认后，后端上传原文件、试看 PDF、缩略图到单一 COS 私有桶并写入文档记录。

## 后端

1. 新增文件真实性校验与本地文档处理器，支持 PDF、DOC、DOCX、PPT、PPTX、XLS、XLSX、TXT。
2. 固定试看规则：2 页文档试看 1 页，3 页及以上试看 2 页，单页拒绝。
3. 新增绑定管理用户、30 分钟过期的临时上传会话；会话目录和所有文件拒绝符号链接。
4. 新增预处理、缩略图读取、缩略图替换、取消、确认保存接口。
5. 确认保存时依次上传原文件、试看 PDF、缩略图；任一步或数据库事务失败时删除本次已上传对象并保留会话。
6. 数据库提交成功后清理本地会话；不写完整 PDF 对象键。
7. 上架条件改为只要求原文件、试看 PDF、缩略图和正确页数。

## 管理端

1. 新增弹窗选择文件并调用预处理接口。
2. 处理完成后展示格式、总页数、自动试看页数和受保护缩略图。
3. 支持替换缩略图；未处理文件禁止保存。
4. 点击确定调用会话确认接口，成功后关闭并刷新；失败保留会话重试。
5. 关闭新增弹窗时取消未提交会话。
6. 删除列表中的“上传原文件”入口和手工预览页数、封面地址字段。

## 验证

- 后端单元测试覆盖页数规则、缩略图生成、格式白名单、会话归属和过期、COS 与数据库补偿。
- 后台 Controller MockMvc 覆盖 multipart 预处理、缩略图读取/替换、取消和 JSON 确认。
- 前端源代码测试覆盖两阶段交互和旧入口移除。
- 测试不连接真实 COS，不执行数据库迁移或部署。
