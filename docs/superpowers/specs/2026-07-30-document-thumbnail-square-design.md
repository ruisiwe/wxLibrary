# 文档列表缩略图正方形完整展示设计

## 目标

所有使用 `document-row` 组件的文档列表统一以正方形展示缩略图，并完整显示图片内容，避免封面被裁剪。

## 修改范围

- 首页文档列表
- 分类文档列表
- 搜索结果
- 我的收藏
- 我的文档

这些页面共用 `miniprogram/components/document-row`，因此只修改该组件，不分别调整各页面。

## 展示规则

- 缩略图固定为 `144rpx × 144rpx`。
- 图片展示模式由 `aspectFill` 改为 `aspectFit`。
- 保留现有圆角和列表布局，缩略图底色统一为白色。
- 图片比例不是正方形时允许留白，以保证图片内容完整显示。

## 验证

- 检查组件模板使用 `aspectFit`。
- 检查缩略图宽高均为 `144rpx`。
- 运行小程序相关测试，并检查本次差异未影响其他工作区改动。
