# 宣传图片关联文档搜索选择设计

## 目标

将管理端宣传图片新增、编辑弹窗中的“关联文档编号”手工输入改为可搜索选择。管理员可以查找文档并查看其可关联状态，只有已发布且分类可用的文档能够选择；前端内部仍提交文档编号，后端继续校验关联文档状态。

## 交互设计

宣传图片表单中的字段名称由“关联文档编号”改为“关联文档”，使用远程搜索单选下拉框：

- 禁止管理员手工输入文档编号。
- 打开下拉框时加载最多 20 条匹配文档，可关联文档优先显示。
- 输入文档标题、分类名称或文件格式关键词后延迟约 300 毫秒发起搜索，避免每次按键都立即请求。
- 每个选项展示文档标题、所属分类、文件格式和中文可关联状态，不以编号作为选择依据。
- 草稿、分类停用或分类不可用的匹配文档仍显示在搜索结果中，但必须禁选并说明原因。
- 选择结果在表单中显示文档标题，内部值仍为 `documentId`。
- 关联文档为必选项，未选择时提示“请选择关联文档”。

宣传图片管理列表中的“关联文档”列显示文档标题，不再只显示文档编号。

## 编辑回显

- 编辑宣传图片时，后端列表或详情数据同时返回关联文档标题，前端可直接回显当前选择。
- 后端同时返回 `documentSelectable`，说明当前关联文档是否仍可选择。
- 如果原关联文档已经下架、删除或所属分类已经停用，当前关联项标记为不可用，并提示“原关联文档已下架，请重新选择”。
- 不可用的原关联项不能继续提交；管理员必须重新选择有效文档。

## 查询接口

新增宣传图片专用的轻量文档选项接口：

`GET /library/banner/document-options`

查询参数：

- `keyword`：可选，按文档标题、分类名称或文件格式模糊查询。
- `pageNum`：页码，默认 1。
- `pageSize`：每页数量，默认且最大为 20。

返回选项只包含：

- `id`：文档编号，仅用于表单内部提交。
- `title`：文档标题。
- `categoryName`：分类名称。
- `fileFormat`：文件格式。
- `documentSelectable`：当前是否允许关联。
- `availabilityStatus`：供前端转换为中文提示的可关联状态。

接口不返回原文件、浏览 PDF、缩略图等对象存储键或其他无关文档字段。不可选文档仅用于说明状态，不能提交为有效关联。

## 查询范围与权限

搜索范围包含未删除的匹配文档。可选文档必须同时满足：

- 文档未删除。
- 文档状态为已发布。
- 所属分类未删除且已启用。

接口属于宣传图片编辑流程，使用宣传图片新增或编辑权限控制，不要求操作员额外拥有完整的文档管理列表权限。

## 前端组件边界

使用现有通用远程搜索选择组件，支持：

- 远程搜索函数。
- 搜索加载状态。
- 选项标签和值字段映射。
- 初始选项和编辑回显。
- 可配置的搜索延迟。

宣传图片页面负责提供文档选项搜索函数、字段配置和中文状态映射，不在选择组件中耦合文档业务规则。

## 后端数据边界

- 使用轻量文档选项 DTO 返回允许公开给宣传图片表单的字段。
- 宣传图片列表和详情返回 `documentTitle` 和 `documentSelectable`，供列表展示、编辑回显和失效状态提示。
- 保存请求仍只接受 `documentId`，不信任前端提交的文档标题。
- 新增和修改宣传图片时在服务层与数据库原子条件中同时校验“文档已发布且分类启用”，防止搜索后文档或分类状态发生变化。
- 不新增数据库表，不修改现有宣传图片与文档的关联字段。

## 错误处理

- 搜索失败时在下拉框显示简体中文提示，保留表单中其他已填写内容。
- 搜索无结果时显示“未找到匹配的文档”。
- 提交前文档状态发生变化时，后端返回“关联文档已下架，请重新选择”。
- 未选择关联文档时不发送保存请求。

## 验证范围

- 标题、分类名称或文件格式关键词可以模糊搜索文档。
- 未输入关键词时最多返回 20 条文档，可关联文档优先。
- 草稿、下架以及所属分类停用的匹配文档显示为中文禁选项；已删除文档不出现在结果中。
- 查询接口只返回约定的轻量字段。
- 新增宣传图片可以选择文档并正确保存 `documentId`。
- 编辑宣传图片可以回显文档标题并更换关联文档。
- 原关联文档不可用时要求重新选择。
- 宣传图片列表显示文档标题，不再只显示编号。
- 搜索期间有加载状态，连续输入不会产生无控制的重复请求。
- 后端保存校验继续拒绝无效或状态已变化的文档。

## 不在本次范围

- 不支持宣传图片同时关联多个文档。
- 不允许选择草稿、已下架或所属分类不可用的文档。
- 不改变宣传图片在小程序首页的跳转逻辑。
- 不调整文档发布、下架和分类启停规则。
