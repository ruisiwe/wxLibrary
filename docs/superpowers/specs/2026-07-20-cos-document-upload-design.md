# COS 文档处理设计

## 1. 目标

微信文库统一使用腾讯云 COS 私有桶 `file-1302202133`，地域为 `ap-beijing`。

管理端浏览器上传文档到后端，后端同步完成格式校验、PDF 处理和缩略图生成；管理员预览缩略图并确认后，后端将三个最终文件上传 COS 并写入数据库。

文档文件处理和转换不作为独立的管理步骤暴露。小程序不在线打开完整 PDF 或原始 Office 文件，只打开试看 PDF；兑换后提示用户将原文件发送到本地后打开。后续 Office 在线查看不在本次范围内。

## 2. 配置

沿用现有 `library.cos` 单桶配置，不增加双桶字段：

```yaml
library:
  cos:
    region: ap-beijing
    bucket: file-1302202133
    secret-id: ${TENCENT_COS_SECRET_ID}
    secret-key: ${TENCENT_COS_SECRET_KEY}
```

桶名称使用 `file-1302202133`，不填写完整 HTTPS 地址。永久密钥只允许由后端外部运行环境注入，不得写入代码、前端或提交到 Git。

文档临时会话复用 `library.document-conversion.temp-directory` 对应的受控临时根目录，并在其下创建独立会话子目录。

## 3. 文档格式与试看规则

允许上传以下格式：

- PDF
- DOC、DOCX
- PPT、PPTX
- XLS、XLSX
- TXT

后端必须同时校验扩展名、MIME 类型和真实文件内容，不得只相信浏览器提供的文件名或 `Content-Type`。

试看页数完全由后端根据完整文档总页数决定，管理端不再显示或提交试看页数：

| 总页数 | 处理结果 |
| --- | --- |
| 1 页 | 拒绝上传，返回“文档总页数不能少于2页” |
| 2 页 | 生成前1页试看 PDF |
| 3 页及以上 | 生成前2页试看 PDF |

数据库中的 `preview_pages` 由后端写入计算结果，不能由前端覆盖。

## 4. 文档两阶段流程

### 4.1 第一阶段：预处理与缩略图预览

管理端新增文档弹窗先收集原文件。选择文件后，管理员点击“处理文件”，前端调用：

```http
POST /library/document-upload/prepare
Content-Type: multipart/form-data
```

请求只包含 `file`，不创建文档记录，也不上传 COS。

后端执行以下步骤：

1. 校验当前管理用户具有文档新增和上传权限。
2. 创建随机、不可预测的临时会话编号和独立临时目录。
3. 将上传内容写入受控临时文件，并在写入过程中执行大小限制。
4. PDF 原文件直接进入 PDF 处理；其他允许格式通过受限 LibreOffice 进程转换为临时完整 PDF。
5. 读取完整 PDF 总页数；单页文档立即拒绝。
6. 根据总页数生成前1页或前2页试看 PDF。
7. 将完整 PDF 第一页渲染为 JPG 自动缩略图。
8. 保留原文件、试看 PDF、最终缩略图三个临时文件；删除只用于处理的完整转换 PDF。
9. 返回临时会话信息和受保护的缩略图地址。

响应数据结构：

```json
{
  "sessionId": "随机会话编号",
  "originalFileName": "质量手册.docx",
  "fileFormat": "DOCX",
  "fileSize": 123456,
  "pageCount": 30,
  "previewPages": 2,
  "thumbnailUrl": "/library/document-upload/session/{sessionId}/thumbnail",
  "expiresAt": "2026-07-20T16:30:00+08:00"
}
```

临时缩略图通过以下受保护接口返回，不暴露服务器真实路径：

```http
GET /library/document-upload/session/{sessionId}/thumbnail
```

### 4.2 自定义缩略图

管理员可以在最终保存前替换当前临时会话的缩略图：

```http
PUT /library/document-upload/session/{sessionId}/thumbnail
Content-Type: multipart/form-data
```

允许 JPG、PNG、WebP，最大 5MB、最大 2000 万像素。后端必须解码真实图片，拒绝伪造扩展名、MIME、异常尺寸和解码失败文件。最终缩略图统一去除异常元数据并重新编码为 JPG，最长边不超过 800 像素且保持比例。

文档保存后仍允许替换缩略图。保存后替换必须上传新版本对象，数据库提交后删除旧对象；数据库更新失败时删除新对象并保留旧对象。

### 4.3 第二阶段：确认保存

管理员确认缩略图并填写文档元数据后，前端提交：

```http
POST /library/document-upload/session/{sessionId}/commit
Content-Type: application/json
```

请求包含标题、分类、摘要、标签、积分价格和排序，不包含试看页数、文件格式、页数、对象键或服务器路径。这些值只能来自后端临时会话。

后端执行以下步骤：

1. 校验临时会话存在、未过期且属于当前管理用户。
2. 校验文档元数据和分类状态。
3. 使用临时会话编号构造对象键。
4. 将原文件、试看 PDF、最终缩略图上传 COS。
5. 在数据库事务中新增文档记录并写入三个对象键、总页数、后端计算的试看页数和处理成功状态。
6. 数据库提交成功后删除本地临时会话。
7. 返回文档编号、处理结果和 COS 缩略图短时签名 URL。

对象键格式：

```text
documents/{sessionId}/original/v1.{扩展名}
documents/{sessionId}/preview/v1.pdf
documents/{sessionId}/thumbnail/v1.jpg
```

现有字段用途调整为：

- `original_object_key`：原文件对象键。
- `preview_object_key`：试看 PDF 对象键。
- `cover_url`：缩略图对象键；对外返回时转换为短时签名 URL。
- `full_object_key`：本流程不再写入，也不再作为发布条件。
- `page_count`：完整文档总页数。
- `preview_pages`：后端计算出的1或2。
- `conversion_status`：最终保存后为 `SUCCESS`。

## 5. 临时会话与清理

临时会话默认有效期为30分钟，并绑定创建它的管理用户。任何其他用户即使获得会话编号也不能读取缩略图、替换缩略图、提交或取消会话。

取消接口：

```http
DELETE /library/document-upload/session/{sessionId}
```

前端关闭新增弹窗时主动取消未提交会话。后台清理任务兜底删除过期会话。清理必须限制在配置的临时根目录内，并拒绝根目录、会话目录、父目录或文件为符号链接的路径。

临时会话至少记录：创建用户、创建时间、过期时间、原始文件名、格式、文件大小、总页数、试看页数和三个受控临时文件名。浏览器不能提交或修改临时文件路径。

## 6. 事务与文件补偿

COS 与数据库不能参加同一个事务，最终保存采用显式补偿：

- 任意 COS 上传失败：删除本次已经上传的 COS 对象，保留临时会话供用户重试。
- 数据库写入或提交失败：删除三个新 COS 对象，保留临时会话。
- 数据库提交成功：删除本地临时会话。
- 本地清理失败：记录不包含密钥、签名 URL 和敏感路径的安全日志，由过期清理再次处理；不能把已成功业务响应改为失败。
- 补偿删除失败：记录对象键和安全错误用于后续运维处理，不返回云端异常详情。

只有三个 COS 对象上传成功且数据库事务提交后，接口才能返回“保存成功”。

## 7. 管理端页面

“新增文档”弹窗调整为：

1. 选择原文件。
2. 点击“处理文件”，等待后端同步处理完成。
3. 展示文件格式、总页数、自动试看页数和缩略图。
4. 允许替换缩略图。
5. 填写标题、分类、摘要、标签、积分价格和排序。
6. 点击“保存”，触发最终 COS 上传和数据库写入。

文件处理期间弹窗显示明确的等待状态并禁止重复提交。处理失败保留表单元数据但清除无效会话。最终保存失败时保留有效会话和缩略图，允许重试。

移除管理端文档列表的“上传原文件”按钮，不再把“执行转换”作为普通管理流程。编辑文档本次只修改元数据；原文件替换不在本次范围内。

## 8. 小程序访问规则

- 小程序在线浏览只使用试看 PDF。
- 不提供完整 PDF 在线阅读。
- 不调用 `wx.openDocument` 打开完整 DOC、DOCX、XLS、XLSX、PPT 或 PPTX。
- 删除现有“打开完整 PDF”按钮及 `/wx/documents/{id}/full` 使用链路。
- 兑换后保留原文件发送、保存或分享能力，并提示“请将原文件发送到本地后打开”。
- Office 在线查看作为未来独立需求，不在本次设计中预留未受控公开接口。

## 9. 文件发送免责声明与客服

### 9.1 后台配置

后台协议管理增加 `FILE_DISCLAIMER`（文件发送免责声明）类型，复用现有 `wl_agreement` 和 `wl_user_agreement`，不新建数据库表。

管理员可以维护免责声明的标题、正文、版本、生效时间和发布状态。同一时间只使用当前生效版本。文件发送免责声明不加入登录协议，首次登录、协议更新拦截和登录状态校验仍然只要求 `PRIVACY` 与 `STATEMENT`。

初始正文由管理员通过后台配置并发布：

```text
1.本账号转载资源均收集于网络，只做参考学习用途，请勿在未经版权所有者书面授权的情况下，用于商业用途或非法用途，违者后果自负!

2.若您喜欢这些资源，请购买正版，所有资源版权归原作者和出版社所有，如有侵权争议，请联系客服下架相关资源。

3。涉及版权文件，请勿私自传播，务必在下载后24小时内从您的设备彻底删除。
```

正文不能硬编码在小程序中。当前免责声明未发布时禁止发送原文件，并返回“文件发送免责声明暂未发布，请联系客服”。

### 9.2 发送前确认

小程序每次点击“发送原文件”时，先调用受保护接口查询当前生效的免责声明及当前用户对该版本的免提示状态：

```http
GET /wx/documents/file-disclaimer
```

接口返回免责声明编号、版本、标题、正文和 `reminderSuppressed`。未登录用户不能查询免提示状态或申请原文件地址。

当 `reminderSuppressed` 为 `false` 时，小程序显示自定义可滚动弹窗，包含后台正文、默认未选中的“以后不再提示”复选框、“取消”和“已阅读，继续发送”按钮。不能使用可能截断长正文的简单提示框代替。

- 用户取消：不申请短时地址、不下载文件、不调起发送面板。
- 用户确认但不勾选：仅允许本次发送，下次继续提示。
- 用户确认并勾选：在 `wl_user_agreement` 中幂等记录当前用户、当前免责声明、版本、确认时间和 IP；同一版本以后不再提示。
- 后台发布新版本后，旧版本免提示记录自动失效，用户必须重新确认。

原文件授权接口调整为接收免责声明确认信息：

```http
POST /wx/documents/{id}/original
```

后端必须同时校验登录用户状态、文档已兑换、当前免责声明版本，以及“已有当前版本免提示记录”或“本次明确确认”之一。不能只相信前端提交的布尔值，也不能接受已失效版本。校验通过后才签发原文件短时地址并记录原文件访问；微信文件发送面板仍由用户自行选择接收人。

### 9.3 联系客服

“我的”页面增加微信原生 `open-type="contact"` 的“联系客服”入口。无论用户是否登录都显示该入口，以便登录异常、账号停用或版权争议时联系客服。保留现有“意见反馈”入口。

客服会话依赖微信公众平台的客服能力配置；本项目不使用硬编码电话号码或普通网页作为替代入口。

## 10. 错误处理

接口注释、响应和报错全部使用简体中文，不使用 Unicode 转义。对外错误只说明可操作原因，例如：

- “文件格式不支持”
- “文件内容与扩展名不一致”
- “文档总页数不能少于2页”
- “文件处理超时，请重试”
- “临时文件已过期，请重新处理”
- “缩略图格式不支持”
- “文件保存失败，请重试”
- “文件发送免责声明暂未发布，请联系客服”
- “文件发送免责声明已更新，请重新确认”

不得向响应或日志输出永久密钥、签名 URL、LibreOffice 命令行敏感内容或未经清理的云端异常详情。

## 11. 测试策略

严格测试先行，每个生产行为先编写红灯测试并确认失败原因正确，再实现最小代码。

后端测试包括：

- PDF、DOC、DOCX、PPT、PPTX、XLS、XLSX、TXT 白名单和真实内容校验。
- 单页文档拒绝、两页生成1页试看、三页及以上生成2页试看。
- PDF 与非 PDF 统一生成试看 PDF 和第一页缩略图。
- 临时会话归属、过期、取消、路径逃逸和符号链接防护。
- 自定义 JPG、PNG 缩略图解码、像素限制、大小限制和 JPG 归一化。
- 真实 Controller MockMvc multipart 预处理、缩略图读取、替换、取消和最终提交。
- COS 第一、第二、第三个对象上传失败时的逐步补偿。
- 数据库写入、事务回滚和提交异常时的 COS 补偿及临时会话保留。
- 保存后缩略图替换的提交后旧文件删除与回滚补偿。
- 后台允许维护和发布 `FILE_DISCLAIMER`，但登录只要求原有两类协议。
- 未发布免责声明时拒绝原文件授权。
- 未兑换文档不能通过免责声明接口获得原文件。
- 未勾选“以后不再提示”时不写免提示记录，下次仍需确认。
- 勾选后相同版本跳过弹窗，新版本发布后旧记录失效。
- “以后不再提示”并发重复写入按幂等成功处理。
- 原文件授权拒绝过期版本、伪造确认状态和停用用户。
- 所有错误响应均为简体中文安全信息。

前端测试包括：

- 新增文档弹窗不再显示试看页数、封面地址、手工文件格式。
- 未处理文件不能最终保存。
- 处理期间禁止重复提交。
- 处理完成展示总页数、自动试看页数和缩略图。
- 自定义缩略图替换成功与失败状态。
- 最终保存失败保留有效会话以便重试。
- 关闭弹窗取消未提交会话。
- 移除手工上传、手工转换和“打开完整 PDF”入口。
- 原文件发送前显示后台免责声明完整正文。
- 取消免责声明时不请求原文件授权。
- 未勾选时下次继续显示，勾选后同版本不再显示。
- 原文件发送不指定固定接收人。
- 登录和未登录状态下都显示“联系客服”，并使用微信原生客服能力。

测试不得连接真实 COS、不得使用真实密钥、不得执行数据库迁移或部署。COS、LibreOffice 外部边界使用可控替身，文件格式处理使用最小真实样本验证。

## 12. 非目标

- 不让文档浏览器直接上传 COS。
- 不保存完整转换版 PDF 到 COS。
- 不提供完整 PDF 在线阅读。
- 不在线打开完整 Office 文件。
- 不把文件发送免责声明加入登录协议。
- 不为免责声明另建数据库表。
- 不在本次实现文档原文件替换。
- 不执行部署、数据库迁移或真实 COS 上传。
