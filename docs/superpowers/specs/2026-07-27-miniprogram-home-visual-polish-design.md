# 小程序首页视觉修正设计

## 1. 背景

根据当前首页设计草图，首页顶部应有明确的小程序名称“实验室文库”，宣传图片区上方应显示“专题推荐”标题，分类宫格图标需要比裸 `t-icon` 更精致，避免页面看起来像简单组件堆叠。

## 2. 调整范围

- 首页顶部增加品牌标题区，显示“实验室文库”。
- 宣传图片列表前增加“专题推荐”标题，使用左侧强调竖条。
- 分类宫格继续使用后台返回的 TDesign `icon` 名称，但在图标外增加浅色图标外壳、阴影和网格分割。
- 不改变首页数据接口、不改变分类 `icon` 字段契约、不新增数据库表。

## 3. 首页结构

首页按以下顺序展示：

1. 顶部品牌区：深蓝背景，左侧显示“实验室文库”。
2. 专题标题：白底标题行，左侧橙色竖条，文字为“专题推荐”。
3. 专题推荐轮播：继续复用 `promotion-strip`。
4. 分类宫格：继续复用 `category-grid`，但优化图标视觉。
5. 文档列表和状态提示：保持现有行为。

## 4. 分类图标视觉

分类宫格中的图标不直接裸露显示。每个分类项包含：

- `grid__icon-shell`：浅蓝渐变背景、圆角、轻阴影。
- `t-icon.grid__icon`：继续使用 `item.icon || 'file'`。
- `grid__label`：分类名称，保持居中。

网格使用白色整体卡片、细分割线和统一高度，使图标与文字更接近设计草图。

## 5. 验证

新增小程序源码契约测试：

- 首页必须包含“实验室文库”和“专题推荐”。
- 首页样式必须包含品牌区、标题行和标题竖条。
- 分类宫格必须使用 `grid__icon-shell` 包裹 `t-icon`。
- 分类宫格样式必须包含图标外壳、阴影和网格分割。
